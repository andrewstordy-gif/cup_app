## PM pre-implementation clarification

Reviewer flagged ambiguous "participant-only COMPLETE block" wording. This
means block automatic/known-creator release, NOT an exception to the approved
unknown/foreign operator override. A qualified participant-local COMPLETE with
no other known active conflict supplies no creator-global state, hence requires
the same explicit unknown warning/consent. Participant PENDING/IN PROGRESS or
unqualified completion is a known active conflict and remains blocked. No new
owner decision: this preserves R1-142 approval for foreign/unknown sessions and
never treats participant completion as host closure. Author/reviewer/QA informed.
