- Add immutable `local_creator_tasting_completion_events` with schema/version,
  actor/session, canonical snapshot JSON/SHA256 and ISO completion time; FK cleanup
  follows whole-session deletion. Snapshot binds locked setup, existing saved
  revision/content hash, sorted ACTIVE IDs/codes/removal generations/scanned-at,
  and sorted ALL-known IDs/codes/removal generations. Existing base hash already
  covers exact pins/counts/owners/current saved semantic responses. The all-known
  generation vector prevents activation/removal ABA of a blank grey neighbour from
  restoring an older completion when the active set/content later looks identical.

  readable only when all known targets are active and no new sidecar exists. Old
  results, revisions, recovery fingerprints and immutable histories are untouched.
  Corrupt new evidence fails closed; stale new evidence cannot fall back to old
  completion or raw `sessions.status=complete` as reveal authority.
- Repository enrolled state uses matching current coverage evidence and an opaque
  actor/base-revision/membership context token. Internal snapshot/base contents are
  not returned in presentation. Only active Blind members reveal after completion;
  inactive Blind remains hidden. Open policy and old/participant paths unchanged.

  without writes. Success atomically persists immutable evidence/history/COMPLETE;
  idempotent repeat is nonmutating. Final actor/coverage acknowledgement checked

  blank statuses for inactive cards; public reads fence captured actor before and
  after async response loading. Existing full-roster semantic aggregate remains
  structurally validated and unchanged; malformed JSON still fails closed.
