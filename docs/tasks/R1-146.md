Actual source route:

- Details handleVerifySample catches every read/validation exception and returns
  false, also used for wrong UID, payload/settings mismatch and non-ready state.

  stagePendingSampleAddition -> reserveWithDb reserves a fresh code/operation
  before dispatch. Earlier issued codes remain spent. Rejection alone does not
  allocate; following the offered rewrite can allocate another code even though
  the preceding successful write may already contain the right data.
